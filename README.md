# Автоответ на грузы в Google Chat — «lmc -d»

Расширение для Google Chrome. Когда брокер присылает в Google Chat предложение
груза, расширение распознаёт его и сразу отвечает **`lmc -d`**. На остальные
сообщения («привет», «$2460», трекинг, рейт-коны и т. п.) не отвечает.

Пример сообщения, на которое придёт ответ:

```
UF-6212077119 • Hammond, IN → Terrell, TX
Live pickup: Oct 02, 2026, 00:01 - 23:59 CDT
Live dropoff: Oct 05, 2026, 08:00 - 17:00 CDT
Dry van
Pallet (packaging type)
11387 lbs
```

## Установка (5 минут)

1. Скачайте проект: на GitHub нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте в Chrome адрес `chrome://extensions`.
3. Справа вверху включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите
   папку **`extension`** из распакованного архива.
5. Закрепите значок с грузовиком на панели Chrome (значок пазла → булавка).

## Как пользоваться

1. Откройте Google Chat: `https://mail.google.com/chat/` (или чат внутри Gmail).
   Если вкладка уже была открыта — обновите её (F5) после установки.
2. Оставьте вкладку открытой. Компьютер не должен засыпать.
3. Пришло предложение груза в открытом чате → через ~1 секунду уходит ответ `lmc -d`.

Нажмите на значок расширения, чтобы:

- включить / выключить бота;
- поменять текст ответа (по умолчанию `lmc -d`);
- задать, на сообщения какой давности отвечать (по умолчанию 15 минут — на
  старые грузы в истории чата бот не отвечает);
- включить **тестовый режим**: бот только подсвечивает найденный груз жёлтой
  рамкой и пишет в журнал, ничего не отправляя. **Советуем начать с него** и
  убедиться, что всё распознаётся правильно;
- вставить любой текст в поле «Проверить сообщение» и посмотреть, считает ли
  бот его грузом;
- посмотреть журнал: на что и когда бот ответил.

### Несколько брокеров

Бот видит только **открытый** чат. Чтобы он сам открывал новые непрочитанные
личные чаты, включите галочку «Самому открывать непрочитанные личные чаты».
Тогда держите Google Chat в **отдельной вкладке**, в которой вы сами не
работаете: бот переключается между чатами, только если вы ничего не трогали в
этой вкладке последнюю минуту. Функция экспериментальная.

## Как бот понимает, что это груз

Сообщение получает баллы за признаки предложения груза:

| Признак | Пример | Баллы |
| --- | --- | --- |
| Маршрут «Город, ШТАТ → Город, ШТАТ» | `Hammond, IN → Terrell, TX`, `Chicago IL to Dallas TX` | 3 |
| Погрузка | `pickup`, `PU`, `shipper` | 2 |
| Выгрузка | `dropoff`, `delivery`, `DEL`, `consignee` | 2 |
| Тип трейлера | `dry van`, `reefer`, `flatbed`, `53'`, `power only` | 2 |
| Вес | `11387 lbs`, `42k`, `40,000#` | 2 |
| Ставка | `$2460`, `all in`, `rpm` | 2 |
| Дата / время, номер груза, мили, паллеты, слово load | `Oct 02`, `UF-6212077119`, `532 miles` | по 1 |
| Слова после бронирования | `rate confirmation`, `ETA`, `POD`, `invoice`, `tracking` | −4 |

Груз — если набрано **6+ баллов** и есть маршрут (или погрузка + выгрузка).
Если брокер разбил предложение на несколько сообщений, они анализируются вместе.

Бот **не отвечает**:

- на свои собственные сообщения;
- если вы уже ответили после этого груза;
- на старые грузы из истории чата;
- второй раз на тот же груз (даже если чат открыт в двух вкладках);
- если вы в этот момент что-то печатаете в поле ввода этого чата — ждёт, пока
  поле опустеет.

## Ограничения

- Работает, только пока открыт Chrome с вкладкой Google Chat.
- Google иногда меняет устройство страницы чата. Если бот перестал отвечать —
  проверьте в тестовом режиме и в журнале, видит ли он сообщения.

## Для разработчиков

```
extension/
  manifest.json   — описание расширения (Manifest V3)
  detector.js     — распознавание груза (чистая функция, без DOM)
  content.js      — работа со страницей Google Chat: чтение сообщений, отправка ответа
  background.js   — общее состояние: защита от двойных ответов, журнал
  popup.*         — окно настроек
tests/
  detector.test.js  — тесты распознавания
  e2e.test.js       — расширение целиком в Chromium на макете страницы Google Chat
```

```
npm test            # тесты распознавания
npm install         # один раз, ставит Playwright
npm run test:e2e    # сквозные тесты в настоящем Chromium
```
